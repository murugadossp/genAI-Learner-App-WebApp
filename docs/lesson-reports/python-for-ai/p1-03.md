## 2. Curriculum alignment

- **Learner outcome:** Learners can construct, clean, transform, and format text strings using Python single/double/triple quotes, string methods (`.strip()`, `.lower()`, `.replace()`, `.split()`), string immutability, `len()`, and formatted string literals (`f"..."`) to prepare inputs for AI prompts and clean model outputs.
- **Misconception addressed:** (1) Strings are mutable in place (`raw_query.strip()` drops the stripped string without variable reassignment); (2) `.strip()` removes internal spaces between words (it only trims leading/trailing whitespace); (3) Missing `f` prefix in `f"..."` leaks literal `{var}` placeholders into LLM API calls; (4) Quotes and apostrophes syntax errors (`'Don\'t'` vs `"Don't"`); (5) Method chaining left-to-right evaluation order.
- **Prerequisites and adjacent lessons:** Preceded by `p1-01` (Variables and Data Types) and `p1-02` (Operators); followed by `p1-04` (Lists).
- **Out of scope (deliberately left to other lessons):** List indexing, slicing, and mutation methods (reserved for `p1-04 Lists`), tuples/sets (`p1-05`), dictionaries (`p1-06`), control flow (`p1-07`), loops (`p1-08`), regular expressions (`re` module), and file I/O.

  - Correct option position: Index 2 (`Process:    RefunD for Order #881   `).
  - Feedback for wrong options:
    - Option 0: `Because strings in Python are immutable, calling raw_query.strip().lower() without assigning the result returns a new string and leaves raw_query completely unchanged in memory, retaining its original outer spaces and capital D.`

    - Option 3: `The .strip() method removes only leading and trailing whitespace, never spaces between words. Furthermore, because raw_query was not reassigned, it retained its original spacing.`

## 5. Decisions and deviations

- **Decision:** Ground the lesson in an authentic AI Customer Support webhook pipeline (`raw_query = "   RefunD for Order #881   "`).
  - **Reason:** Provides an immediate, practical engineering rationale for every string operation (`.strip()`, `.lower()`, `.replace()`, `f"..."`, `len()`) without artificial toy examples.
- **Decision:** Pair casing differences (`RefunD` vs `refund`) with leading/trailing spaces in the knowledge check.
  - **Reason:** Addressed finding P2-2 from Gate 1 Review; web browsers collapse multiple consecutive spaces inside HTML labels. Casing preserves an unambiguous, visual indicator of immutability across all browsers.
- **Decision:** Keep `webStatus: "draft"` in `meta.json`.
  - **Reason:** Adheres strictly to repo rules; publishing requires an explicit user command and formal publication PR.
