## 2. Curriculum alignment

- **Learner outcome:** Explain what a pandas `DataFrame` and `Series` are, create a small `DataFrame` from a dictionary of equal-length lists, select a single column with `df["col"]`, and compute whole-column totals and averages with `.sum()` and `.mean()` instead of writing manual accumulator `for` loops. (Curriculum entry `P1.12` "Introduction to pandas", Core, needs `P1.11`. The curriculum snapshot holds only the title, tag, order, and prerequisites, so the outcome wording is scoped to fit before `P1.13` and `P1.14`.)
- **Misconceptions addressed:**
  1. Confusing a 2D `DataFrame` (whole table) with a 1D `Series` (a single selected column).
  2. Writing `df[tokens]` without quotes and expecting pandas to treat it as the `"tokens"` column label (`NameError` in a fresh script with no `tokens` variable).
  3. Assuming `.sum()` or `.mean()` mutates the `DataFrame` in place instead of returning a new summary number.
  4. Thinking you still need to write a manual accumulator `for` loop to total or average a column in pandas.
- **Prerequisites and adjacent lessons:** `P1.11` (Errors and safe parsing, open draft PR #60) and earlier Python fundamentals (`P1.1`–`P1.10`). Next: `P1.13` (Columns and tables) and `P1.14` (Filtering rows).
- **Out of scope (deliberately left to other lessons):** Multi-column selection (`df[["a", "b"]]`), `df.shape`, `df.head()` (`P1.13`); row filtering / boolean masks (`P1.14`); reading CSV/JSON files (`pd.read_csv`), missing values (`NaN`), custom row indexes, `loc`/`iloc`, and installing packages/virtual environments (one-line pointer only).
