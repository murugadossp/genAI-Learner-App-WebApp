## 2. Curriculum alignment

- **Learner outcome:** Inspect a pandas DataFrame's dimensions, column names, and top rows (`df.shape`, `df.columns`, `df.head(n)`); select a single column as a 1D Series (`df["col"]`) versus a list of columns as a 2D DataFrame (`df[["col1", "col2"]]`); and create a new derived column from existing columns (`df["total_tokens"] = df["in_tokens"] + df["out_tokens"]`).
- **Misconception addressed:** Dropping the inner list brackets when selecting multiple columns (`df["model", "in_tokens"]`, which passes a tuple key and raises `KeyError` in this DataFrame), calling tuple/Index attributes with parentheses (`df.shape()`), and confusing non-mutating column selection with in-place column assignment.
- **Prerequisites and adjacent lessons:** Prerequisite `P1.12` (`p1-12`, "Introduction to pandas"); next lesson `P1.14` (`p1-14`, "Filtering rows").
- **Out of scope (deliberately left to other lessons):** Boolean masks, row filtering (`df[df["col"] > ...]`), `.loc[]` / `.iloc[]` row selection, `.query()`, `.groupby()`, `.merge()`, and CSV file I/O (left to `P1.14` and later).

- **Interaction:** `TableWorkbench` ("Column & Table Workbench") — a staged 2-step toy simulator (clearly disclosed as illustrative with no live Python runtime). Stage 1 lets the learner toggle columns (`model`, `in_tokens`, `out_tokens`, and `total_tokens` once added) and, when 1 column is selected, switch between single brackets `df["col"]` (1D Series, shape `(5,)`) and a 1-item list `df[["col"]]` (2D DataFrame, shape `(5, 1)`), while observing that original `df.shape` remains unchanged. Stage 2 adds `total_tokens` via `df["total_tokens"] = df["in_tokens"] + df["out_tokens"]`, clearly labeling the status as `Updated table: df (DataFrame)` and `Updated df.shape: (5, 4)` to contrast in-place assignment with column selection. ## 5. Decisions and deviations

- **Staged 2-step lab instead of a 3-control workbench:** Removed the redundant `df.head(2)` row-preview toggle from the lab after Gate 1 P2 feedback so phone users can focus cleanly on column selection and derived-column assignment.
- **Mobile 5-column table sizing:** After inspecting 390px screenshots by eye, tightened mobile `.labBox` padding (`0.85rem`) and `.dataTable` cell padding/font-size (`0.75rem`, `0.42rem 0.3rem`) so all 5 columns (`Index`, `model`, `in_tokens`, `out_tokens`, `total_tokens`) fit completely on a 390px screen without clipping or mid-word wrapping.
- **Local `Check.tsx` wrapper:** Included a lesson-local `Check.tsx` matching `p1-12/Check.tsx` (adds `aria-describedby` linking the `<fieldset>` to its status live region and renders `<div>` for inline quick checks without touching shared `src/lessons/Check.tsx`).
- **Image provider fallback:** Used `agy generate_image (default model)` first per `tooling.yaml` (`inspect-table.webp` succeeded on first try). When regenerating `derived-column` after catching a row-order mismatch by eye, `agy` returned `429 RESOURCE_EXHAUSTED` on `gemini-3.1-flash-image` (~5h cooldown). Per `tooling.yaml`, fell back to `codex` for `select-columns.webp` (r2, fixing arrow layout) and `derived-column.webp` (r2, fixing row order).
