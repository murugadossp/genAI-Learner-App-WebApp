## 2. Curriculum alignment

- **Learner outcome:** Read and write a `for` loop over a list, use an accumulator, use `break` and `continue`, and write a `while` loop whose condition eventually becomes `False`. (Curriculum entry P1.8 "Loops", needs P1.7.)
- **Misconception addressed:** (a) `for x in items` gives the position of each item. It gives the item itself. (b) `continue` ends the loop. It skips only the rest of one pass.
- **Prerequisites and adjacent lessons:** P1.7 (if-else), P1.4 (lists and indexing), P1.6 (`len()`); next lesson P1.9 (functions).
- **Out of scope (left to other lessons or later):** `range()` beyond a one-line pointer, `enumerate()`, list comprehensions, nested loops, loops over dictionaries, `for`/`else`, functions.
