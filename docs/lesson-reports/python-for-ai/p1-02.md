## 2. Curriculum alignment

- **Learner outcome:** Learners can use Python arithmetic (`+`, `-`, `*`, `/`, `//`, `%`, `**`), comparison (`==`, `!=`, `<`, `<=`, `>`, `>=`), and logical (`and`, `or`, `not`) operators to calculate pipeline metrics (token chunking, remainders, power-of-two context scaling), evaluate condition thresholds (equality vs assignment), and combine boolean rules with clear parentheses.
- **Misconception addressed:** (1) True division (`/`) returns an integer when dividing evenly (`10 / 2` evaluates to float `5.0`); (2) Confusion between floor division (`//`) and modulo (`%`); (3) Assignment (`=`) vs equality comparison (`==`); (4) Exponentiation (`**`) vs bitwise XOR (`^`); (5) Operator precedence and grouping without parentheses.
- **Prerequisites and adjacent lessons:** Preceded by `p1-01` (Variables and Data Types); followed by `p1-03` (Strings).
- **Out of scope (deliberately left to other lessons):** Control flow (`if`/`elif`/`else` in `p1-07`), loops (`p1-08`), string slicing & formatting (`p1-03`), and compound collections (lists in `p1-04`, tuples/sets/dicts in `p1-05`, `p1-06`).

  - Question: `An AI document chunker receives a document of 1350 tokens and splits it into chunks of 500 tokens. Which Python expression correctly calculates the number of leftover tokens in the final incomplete chunk?`

  - Feedback for wrong options:
    - Option 0: `True division (/) produces the floating-point ratio 2.7, not the integer count of leftover tokens.`
    - Option 1: `Floor division (//) computes the number of complete chunks (2), not the remainder left over.`
    - Option 3: `The caret (^) is bitwise XOR in Python, which computes 1202 for these inputs, not a remainder or power.`

## 5. Decisions and deviations

- **Decision:** Provide dual visual representations: a dedicated responsive code-based SVG diagram (`TokenChunkVisual.tsx`) and a high-resolution educational infographic diagram (`python-operators-model.jpg`).
  - **Reason:** The code-based diagram provides crisp interactive token chunk rendering that scales responsively across viewports, while the generated infographic provides an intuitive multi-panel mental model connecting the division trio, exponentiation vs XOR, and equality comparisons.
- **Decision:** Use an authentic context & empty request validation guard (`needs_warning = (total_tokens > 1024) or (total_tokens <= 0)`) for `or` logic.
  - **Reason:** Addressed finding P2 from Gate 2 Review Round 1; previous chunking guard had a subtle logic bug when token counts were smaller than chunk size. The new guard accurately models AI API validation and short-circuits cleanly.
- **Decision:** Keep `webStatus: "draft"` in `meta.json`.
  - **Reason:** Adheres strictly to repo rules; publishing requires an explicit user command and formal publication PR.
