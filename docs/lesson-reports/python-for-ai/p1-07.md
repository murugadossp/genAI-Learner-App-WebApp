## 2. Curriculum alignment

- **Learner outcome:** Write an if / elif / else chain; explain that the first true branch runs and that else runs only when no test above it is true; choose >= or > at a boundary (curriculum entry P1.7, `p1-07`, needs P1.6).
- **Misconceptions addressed:** (1) every true test runs; (2) a looser test placed first catches values meant for a stricter one; (3) >= and > differ at the boundary value; (4) else has a condition; (5) = assigns and == compares; a chain without else can run nothing.
- **Prerequisites and adjacent lessons:** p1-06 (dictionaries, needed before p1-08 loops). Cross-link to c2-06 (context window) for the running example's background.
- **Out of scope (left to other lessons):** and / or, nested if, loops (p1-08), try / except (p1-11), and the mobile lesson's scoring example.
