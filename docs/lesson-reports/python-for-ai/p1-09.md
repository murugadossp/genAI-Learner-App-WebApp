## 2. Curriculum alignment

- **Learner outcome:** write a small `def`, call it, use a default value, tell `return` from `print`, and read what a call hands back. Curriculum entry P1.9 "Functions", slug `p1-09`, needs P1.8 (Loops).
- **Scope taken from the curriculum and the mobile authoring notes (scope only; no mobile prose or answers copied):** def and call, parameters and arguments, default values, return vs print, a function with no `return` gives `None`, docstrings.
- **Misconceptions addressed:** (1) writing `def` runs the function; (2) `print` and `return` do the same thing; (3) a function with no `return` gives nothing (it gives `None`).
- **Out of scope:** `*args`/`**kwargs`, `lambda`, scope rules, modules (P1.10), recursion, mutable default values.
- **Running example:** `make_title(topic, prefix="Chat")` returns `prefix + ": " + topic`. Invented, text only, no arithmetic. Constraints: the default `"Chat"` and the separator `": "` are made up for this lesson.
