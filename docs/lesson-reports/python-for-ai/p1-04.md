## 2. Curriculum alignment

- **Learner outcome:** Learners can construct, index, slice, and mutate Python lists (`list`) using square brackets `[...]`, 0-based positive indexing (`docs[0]`), negative indexing from the tail (`docs[-1]`), slicing (`docs[start:stop]`), built-in `len()`, and in-place mutation methods (`.append()`, `.pop()`) to manage ordered candidate passages, message histories, and token sequences in AI pipelines without falling into the `.append()` variable rebinding trap.
- **Misconception addressed:** (1) The `.append()` return trap: writing `docs = docs.append(...)` rebinds the variable to `None`; (2) 1-based indexing causing off-by-one errors (Python sequences start at index 0); (3) Slicing stop index inclusivity: `[start:stop]` stops before `stop`; (4) Slicing vs indexing out-of-bounds: single indexing throws `IndexError`, whereas slicing clips safely without error; (5) Mutability vs immutability: lists mutate in place in memory, unlike strings.
- **Prerequisites and adjacent lessons:** Preceded by `p1-03` (Strings), `p1-02` (Operators), and `p1-01` (Variables and Data Types); followed by `p1-05` (Tuples and Sets).
- **Out of scope (deliberately left to other lessons):** Tuples and Sets (`p1-05`), Dictionaries (`p1-06`), Conditionals (`p1-07`), Loops (`p1-08`) including list comprehensions, and sorting algorithms (`.sort(key=...)`).

## 5. Decisions and deviations

- **Decision:** Ground the lesson in an authentic AI Retrieval-Augmented Generation (RAG) candidate ranking pipeline (`retrieved_docs = ["refund_policy", "shipping_faq", ...]`).
  - **Reason:** Provides an immediate engineering purpose for indexing top matches (`[0]`), inspecting tail candidates (`[-1]`), slicing context budgets (`[:2]`), and appending fresh context (`.append()`).
- **Decision:** Explicitly disclose that slicing selects items strictly by sequential position and does not measure token length.
  - **Reason:** Addressed finding from Gate 1 Review; prevents learners from confusing list item slicing with token budget enforcement.
- **Decision:** Provide interactive buttons with `aria-pressed` and live regions for list slots and modes.
  - **Reason:** Addressed finding from Gate 2 Review Round 4; ensures list slots are discoverable, operable, and announced to assistive technologies.
- **Decision:** Keep `webStatus: "draft"` in `meta.json`.
  - **Reason:** Adheres strictly to repo rules; publishing requires an explicit user command and formal publication PR.
