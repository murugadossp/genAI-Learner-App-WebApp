## 2. Curriculum alignment

- **Learner outcome:** Distinguish Python tuples (ordered, immutable sequences created with parentheses and commas, unpacked into variables, requiring a trailing comma for a 1-item tuple) from sets (unordered, unindexed collections of unique hashable items created with `{...}` or `set()`, deduplicating automatically and supporting `in` membership checks and `.add()`).
- **Misconception addressed:**
  1. Thinking `("billing")` or `("rag")` without a trailing comma creates a 1-item tuple (it evaluates to a plain `str`; a 1-item tuple requires a trailing comma such as `("billing",)`).
  2. Thinking `{}` creates an empty set (`{}` creates an empty `dict`; an empty set requires `set()`).
  3. Expecting a set to preserve index order or support `unique_sources[0]` (sets are unordered and unindexed; indexing raises `TypeError: 'set' object is not subscriptable`).
  4. Attempting to overwrite a tuple slot in place (`model_spec[1] = 8192` raises `TypeError: 'tuple' object does not support item assignment`).
- **Prerequisites and adjacent lessons:** Prerequisite is `p1-04` (`P1.4`: Lists), building on `p1-01` (Variables and Data Types), `p1-02` (Operators), and `p1-03` (Strings). Followed by `p1-06` (`P1.6`: Dictionaries).
- **Out of scope (deliberately left to other lessons):** Key-value dictionary operations (`p1-06`, except noting that `{}` creates an empty `dict`), `if/else` control flow (`p1-07`), `for`/`while` loops (`p1-08`), functions (`p1-09`), set algebra operators (`|`, `&`, `-`), and `collections.namedtuple`.
