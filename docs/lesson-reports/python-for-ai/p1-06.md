## 2. Curriculum alignment

- **Learner outcome:**
  1. Explain that a Python dictionary (`dict`) stores data as `key: value` pairs and retrieves values by key name rather than by numerical position.
  2. Read values with bracket syntax `dict[key]` and contrast `dict[0]` raising `KeyError: 0` with positional list indexing.
  3. Safely handle missing keys using `dict.get(key, default)` (returns default or `None` without error or mutation) and `'key' in dict` (membership check returning boolean).
  4. Distinguish updating an existing key from inserting a new key via `dict[key] = value`, and identify the common typo trap (e.g. `ticket['priorty'] = 'low'` creates an extra key instead of updating `'priority'`).
  5. Navigate nested dictionaries sequentially (`dict[outer][inner]`) and explain why `dict[inner]` raises `KeyError`.
  6. Choose between a `list` (ordered sequence of similar items) and a `dict` (record of named entity attributes) using the primary lookup criterion: *How will you primarily look up an item?*
- **Misconception addressed:**
  1. Expecting `ticket[0]` or `ticket[1]` to access dictionary values by sequential index (raises `KeyError` unless `0` is an actual key; dictionaries access by key name, not position).
  2. Assuming `ticket['assignee']` returns `None` or an empty string when the key is absent (raises `KeyError: 'assignee'`).
  3. Assuming `.get()` mutates the dictionary or inserts a missing key (it is strictly a non-mutating read operation returning a default or `None`).
  4. Expecting typo keys like `ticket['priorty'] = 'low'` to error or update `'priority'` (it silently inserts a new key `'priorty'`).
  5. Looking up a nested key directly at the top level `ticket['plan']` instead of navigating sequentially `ticket['customer']['plan']` (raises `KeyError: 'plan'`).
- **Prerequisites and adjacent lessons:** Prerequisites `p1-01` (Variables and Data Types), `p1-02` (Operators), `p1-03` (Strings, method dot notation), `p1-04` (Lists), `p1-05` (Tuples and Sets). Followed by `p1-07` (If-else statements) and `p1-08` (Loops).
- **Out of scope (deliberately left to other lessons):** `if`/`else` control flow (`p1-07`), loops (`p1-08`), functions (`p1-09`), dictionary comprehensions, dictionary methods like `.pop()`, `.update()`, `.items()`, `.keys()`, `.values()`.
