## 2. Curriculum alignment

- **Learner outcome:** Learners can explain how Python variables name values in memory, distinguish the four core primitive types (`str`, `int`, `float`, `bool`), identify type mismatches (such as string `"500"` vs integer `500`), and safely convert between types for AI configuration parameters.
- **Misconception addressed:** (1) The `=` operator means mathematical equality rather than name binding; (2) Numbers wrapped in quotes behave like numbers in arithmetic; (3) Python automatically coerces strings to numbers during operations.
- **Prerequisites and adjacent lessons:** No prerequisites in Python for AI (this is lesson P1.1); followed by `p1-02` (Operators).
- **Out of scope (deliberately left to other lessons):** Compound data structures (lists, tuples, dicts in `p1-04` through `p1-06`), control flow (`p1-07`), functions (`p1-09`), and pandas dataframes (`p1-12`).

## 5. Decisions and deviations

- **Decision:** Generalize `LessonFrame` and `Course.tsx` as documented in `AGENTS.md` rather than hardcoding.
  - **Reason:** `AGENTS.md` explicitly specifies generalizing `LessonFrame` and `Course.tsx` with defaults before adding a lesson in another module, so that `Python for AI` displays the correct eyebrow and navigation without altering any existing chapter 2 lessons.
- **Decision:** Add configurable `TEST_PORT` to `playwright.config.ts`.
  - **Reason:** In multi-worktree environments where multiple agents or developers run tests simultaneously, port 3100 can be occupied. Setting `TEST_PORT` allows isolated test runs on distinct ports without altering default behavior in CI or single-user environments.
