- **Interaction:** `StagePlannerLab` lets the learner compare a `Single big prompt` (with a toggle to reveal buried rule breaks across Rules 1–4 inside a fluent reply) against a `3-stage plan` (`1. Extract facts`, `2. Match roles`, `3. Draft email`). At Stage 2, the learner can choose `Skip check → Stage 3` to observe all four unchecked assignment slips carrying directly into the Stage 3 email, or `Check & fix slips → Stage 3` to pass the stage gate and produce a clean 43-word email meeting all four rules. Includes `Reset`, keyboard navigation, and `aria-live="polite"` status announcements.
- **Knowledge check:**
  - Question: Priya asks an AI assistant to plan a community dinner in one prompt using her volunteer notes and rules; the assistant returns a 400-word explanation that sounds clear and thorough. What should Priya do to make sure the schedule is right?
  - Correct option position: index `2` ("Break the work into small stages and check each stage’s output against her notes and rules before moving on.").
  - Wrong option feedback:
    - Option 0 (trust 400-word explanation): explains that length and fluent wording do not prove correctness.
    - Option 1 (ask for an even longer explanation): explains that adding more words does not verify the schedule against notes and rules.
    - Option 3 (keep schedule as-is and shorten email): explains that shortening the email fixes word count only while wrong shifts still carry over.
- **Shared code touched:** none. `LessonFrame` is reused with `chapter={{ label: "Prompting and Working with AI", href: "/course/chapter-3" }}`, and a local `Check.tsx` adds `aria-describedby` without altering shared `src/lessons/Check.tsx`. Existing lessons render unchanged (195/195 Playwright tests pass).
