## 2. Curriculum alignment

- **Learner outcome:** Separate the learned model from interface, data sources and tools; trace one request.
- **Misconception addressed:** The app and the model are one thing.
- **Prerequisites and adjacent lessons:** needs 1.3 (c1-03, not yet on `main`; referenced only as "the previous lesson", no link). Next is 1.5 (c1-05), mentioned by title only.
- **Out of scope:** what happens to a model when an app is used, training, retraining (c1-05); how tools, retrieval or agents work in detail.

## 3. What was built

- **Files added:** `src/lessons/genai-basics/c1-04/` (`Lesson.tsx`, `Trace.tsx`, `Sorter.tsx`, `PartsMap.tsx`, `parts.ts`, `lesson.module.css`, `meta.json`), `tests/web/c1-04.spec.ts`, this report.
- **Interaction:** a six-step trace of one request through the invented "Leaf Buddy" app (Back / Next / Reset). The active part is marked "In use" (text, not colour only) and the step shows what goes in and what comes out. A six-item practice sorter (Interface / Model / Data source / Tool) follows with per-item feedback, score and reset.
- **Knowledge check:** cactus scenario in which a gardener confirms the stored care entry is wrong. Correct option is position 2 of 4 (data source). Wrong options: model (it named the cactus correctly), interface (displays what it is given), tool (weather service gives forecasts, not care tips).
- **Shared code touched:** none. Uses the `chapter` prop `{ label: "AI foundations", href: "/course/chapter-1" }` like c1-01 and c1-02. No generated routes edited.
