## 2. Curriculum alignment

- **Learner outcome:** Explain how units stack into layers and why nonlinear activation steps let a network model curved boundaries.
- **Misconception addressed:** More layers are always better.
- **Prerequisites and adjacent lessons:** `c6-01` is the listed prerequisite; `c6-03` is adjacent and continues into learning/training.
- **Out of scope (deliberately left to other lessons):** Training, gradient descent, and how a network learns its weights.

## 3. What was built

- **Files added or changed:** `src/lessons/genai-basics/c6-02/` (`Lesson.tsx`, `BoundaryLab.tsx`, `lesson.module.css`, `meta.json`); `tests/web/c6-02.spec.ts`; this report.
- **Content added after user feedback (if any):** No direct lesson-content feedback. Independent content review prompted a clearer definition of “nonlinear” and an equation correction; details are in the review log.
- **Interaction:** Learners select one affine rule, two stacked affine rules without an activation, or two units with ReLU activations. The plot and description update, showing that the no-activation stack stays a straight line while the activation version makes a bounded region. Reset returns to the initial selection.
- **Knowledge check:** Why add a nonlinear activation between layers? Correct answer is the third option: it lets stacked layers form boundaries that a single straight-line rule cannot. Wrong option 1 says an extra layer automatically improves every answer; feedback explains added layers are not automatically useful. Wrong option 2 says each hidden unit understands an input; feedback explains a unit performs a fixed calculation rather than understanding. Retry is supported.
- **Shared code touched:** None. `LessonFrame` receives the Chapter 6 label and `/course/chapter-6` URL explicitly. Existing lessons render unchanged because shared components were not changed.
