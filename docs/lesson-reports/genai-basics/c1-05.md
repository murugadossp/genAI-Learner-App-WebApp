## 2. Curriculum alignment

- **Learner outcome:** Distinguish changing a model (training, retraining, adaptation) from using it; a prompt does not retrain it.
- **Misconception addressed:** Training happens once, or every chat retrains the model.
- **Prerequisites and adjacent lessons:** 1.4 (needs); 1.3 (examples and labels, referenced).
- **Out of scope:** training stages (2.3, 2.4), parameters (2.5), fine-tuning detail (7.4, 10.4), cost and latency (11.x).

## 3. What was built

- **Files:** `src/lessons/genai-basics/c1-05/` (`Lesson.tsx`, `meta.json`, `Lab.tsx`, `Sorter.tsx`, `lesson.module.css`, `factory-vending.jpg`, `training.jpg`, `inference.jpg`, `hint.jpg`, `retrain.jpg`), `tests/web/c1-05.spec.ts`, this report.
- **Content added after user feedback ("more detail, more examples, more intuitive images"):** worked example of how v1 learned (three labelled emails) and why it errs, a four-step inference walk-through, a "Call me Sam" chat example, a "same idea elsewhere" line, a v2 retraining example, and a Quick questions section (3 questions). The code-drawn `PhasesMap` was removed because the images replace it.
- **Interaction:** a four-button lab on the invented Ticket Tagger. A hint changes one reply and the learned settings stay v1; only "Train v2" changes the settings. Then a five-item Training/Inference sort with per-item feedback and reset.
- **Knowledge check:** correct option is 3rd (index 2). Wrong options: forgot overnight (nothing learned to forget); training resets daily (nothing resets v1); hint permanently changed v1 (a hint is input to one request, not training).
- **Shared code touched:** none. Passes `chapter` for AI foundations to `LessonFrame`.

## 5. Decisions and deviations

- New running example (Ticket Tagger) instead of Leaf Buddy, to avoid copying lesson 1.4.
- Two-step criterion (settings changed? else, producing an output?) after plan review, since "unchanged" alone does not mean inference.
- Added five generated explainer images (JPEG, 160-190 KB each), one idea per image. The first two-panel hint-vs-training image was replaced after the user said it was unclear. A regenerated draft had also implied inference creates the settings. Lesson prose stays the source of truth.
- Plan review ran one round, not two.
