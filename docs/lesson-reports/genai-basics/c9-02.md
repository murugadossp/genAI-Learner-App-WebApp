## 2. Curriculum alignment

- **Learner outcome:** Classify tasks as fixed workflows, agent loops or combinations (curriculum 9.2, "Fixed steps versus model-selected next actions").
- **Misconception addressed:** Calling a model inside a fixed step makes a system an agent. Also: a coded branch makes a system an agent. The lesson says both are workflows, because the code still picks the next step.
- **Prerequisites and adjacent lessons:** Chapter 9 course page (shared, on `ch09/foundation`). Adjacent: 9.3 agent loop (not built), 9.4 state (planned as `c9-04`), 9.6 failure recovery (planned as `c9-06`).
- **Out of scope:** Tool-calling mechanics (9.1), state and memory (9.4), approval gates (9.5), failure handling (9.6), and evaluation (9.7). Multi-agent coordination has no curriculum entry yet.
