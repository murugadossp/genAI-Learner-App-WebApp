## 2. Curriculum alignment

- **Learner outcome:** Identify examples, input features and labels; recap rules vs learning and unfamiliar cases as practice, not a new explanation.
- **Misconception addressed:** "Features and labels are the same thing."
- **Prerequisites and adjacent lessons:** needs 1.1 (c1-01). Adjacent: c1-02 (jobs AI does), c1-04 (a model is not the app).
- **Out of scope (deliberately left to other lessons):** how training works, kinds of learning (supervised, unsupervised), data quality and bias in depth, model vs app.

## 3. What was built

- **Files added or changed:** `src/lessons/genai-basics/c1-03/` (`meta.json`, `Lesson.tsx`, `data.ts`, `RowDiagram.tsx`, `FruitTable.tsx`, `ChoiceTask.tsx`, `TableLab.tsx`, `lesson.module.css`), `tests/web/c1-03.spec.ts`, this report.
- **Interaction:** a running fruit-crate table (Colour, Shape, Size, Fruit). Each concept section (example, feature, label) shows the same flashcard diagram and a one-question practice with per-option feedback. The lab lets the learner pick Goal A (name the fruit) or Goal B (guess the fruit's size) and mark every column Feature or Label. Feedback is per column, state is kept per goal, and the same column changes role between goals. A final practice asks for the best guess for an unlabeled new fruit.
- **Knowledge check:** school app with Hours slept, Ate breakfast, Arrived late; goal is to predict lateness. Correct option is position 2 of 4 ("Arrived late"). Wrong: Hours slept (a clue, not the "most important" column); Ate breakfast (yes/no does not make a label; recorded before the prediction); all three (columns have different roles here).
- **Shared code touched:** none. `LessonFrame` receives the Chapter 1 `chapter` prop (`/course/chapter-1`), as c1-01 and c1-02 do.

## 5. Decisions and deviations

- Chose a fruit table over a spam or house-price example because it needs no arithmetic and every wrong answer is checkable by reading the table.
- Plan review (Codex) found Goal B ambiguous ("crate size"), so it was reworded to "the fruit's size". Scoping ("in this table"), recap wording and the practice rule were also tightened.
- The quiz uses one goal. Goal-dependence of the role is assessed in the lab, not in the quiz (plan review P3, accepted as a described deviation).
- Used native radio groups instead of tap-to-tag, so keyboard and screen-reader use works without custom widgets.
- No generated image; the flashcard diagram is code.
- Two wording-only edits (round 3 P3 findings) were made after the last clean round; the full suite was re-run after them.
