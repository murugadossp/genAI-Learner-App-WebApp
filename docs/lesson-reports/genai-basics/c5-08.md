- **Learner outcome:** Read a confusion matrix; pick a metric for the cost of errors.
- **Misconception addressed:** Accuracy is enough.
- **Prerequisites and adjacent lessons:** Prerequisites 4.3 and 5.5; adjacent lessons include 5.7 (overfitting and underfitting), 5.9 (data leakage), and 5.10 (performance across groups).

## 5. Decisions and deviations

- Kept one 20-transaction fraud example through the baseline, confusion matrix, metric calculations, and lab; the earlier partial switched between 100- and 20-transaction batches.
- Used three generated illustrations: accuracy’s rare-case trap, actual-versus-predicted matrix orientation, and precision-versus-recall denominators. Each has separate side-by-side `Analogy` and `Key takeaways` cards.
- The Pillow-backed `to_webp.py` conversion was unavailable in the initial authoring environment. The generated images were resized to 1200×800 and encoded as WebP at quality 82 with the repository-installed `sharp` package; the resulting files are about 72 KB, 80 KB, and 80 KB. All three images were visually inspected.
- The plan review (Codex CLI, gpt-6-luna) was clean. Content review (Codex CLI, gpt-6-luna) was also clean after defining TP/FN/FP/TN, clarifying F1 in plain language, and fixing the pressed-button transition and theme-persistence test setup.
- The first Playwright run found low contrast during the active preset's color transition; the pressed style now has no transition and the strengthened hover selector preserves contrast. The next run showed that the test setup rewrote its initial theme on reload; the test now sets the initial value once before navigating. The final full suite passed.
- The lesson branch was rebased onto the latest `origin/main` before verification. The shared Playwright configuration edit from the earlier partial work was removed and is not part of this lesson.
