- **Interaction:** Learner selects among 5 illustrative JSON replies (or edits the JSON directly in the textarea) → the 3-step format validator updates immediately (syntax → exact required fields → allowed values) and announces the result → learner sees how a reply can fail each specific format rule and how `Wrong fact` passes all three format checks yet still gets the location wrong compared to the source note.
- **Knowledge check:** Scenario where a model returns JSON for the four event fields (`event`, `date`, `location`, `cost`) that parses cleanly with all four non-empty fields and `"cost": "free"`. Correct answer is at index `2` ("The reply matches your format rules, and you still need to check that each field's value matches the original email.").
  - Wrong option 0 ("completely accurate because valid JSON guarantees..."): clarifies that valid JSON confirms shape and allowed values, not factual accuracy against the source email.
  - Wrong option 1 ("did not need to validate syntax because asking guarantees..."): clarifies that asking guides the model by default rather than guaranteeing valid syntax.
  - Wrong option 3 ("JSON only works for programmers..."): clarifies that structured formats help anyone inspect and reuse replies, and paragraphs can also contain errors.

## 5. Decisions and deviations

- **Image generation fallback:** Tried `agy-gemini` first per `references/tooling.yaml`; `agy` returned `429 Too Many Requests / RESOURCE_EXHAUSTED` (quota reset ~5h). Fell back to `codex` (second in `tooling.yaml` `image_generation.order`), which generated both 3:2 illustrations cleanly on the first attempt with exact `KEY_ELEMENTS` labels and left-to-right arrows. Converted both to 1200x800 WebP (`54 KB` and `59 KB`).
- **Missing-data rule alignment:** After Plan Review Round 1, included `"unknown"` in the allowed values for `cost` (`"free"`, `"paid"`, or `"unknown"`) so the missing-data rule and allowed-value rule never conflict.
- **Editable JSON in the lab:** Included a live editable `<textarea>` alongside the 5 presets so learners can fix a broken reply (such as deleting wrapper text or renaming `"place"` to `"location"`) and immediately see the validator checks turn green.
