## 2. Curriculum alignment

- **Learner outcome:** Calculate weighted inputs plus a bias, and describe the effect of changing a weight.
- **Misconception addressed:** A neuron is a tiny brain. The lesson describes it as one mathematical calculation.
- **Prerequisites and adjacent lessons:** prerequisite 4.1; adjacent c6-02 and c6-03.
- **Out of scope (deliberately left to other lessons):** How weights are learned, layers, and activation functions beyond brief definitions needed to orient the learner to adjacent material.

## 3. What was built

- **Files added or changed:** `src/lessons/genai-basics/c6-01/{Lesson.tsx,WeightLab.tsx,KnowledgeCheck.tsx,lesson.module.css,meta.json}`; `tests/web/c6-01.spec.ts`; this report.
- **Content added after user feedback (if any):** None.
- **Interaction:** Learners toggle two 0-or-1 signals, adjust each signal's weight, see its contribution, the score, and a toy reminder result, then reset. Bias is held at −1 in the explorer and explained with a separate numeric example.
- **Knowledge check:** Both signals are 0; the question asks which one edit changes the computed score. Correct option is second: change bias from −1 to 0. Increasing the rain weight is ineffective when its input is 0; changing cloud weight is ineffective when its input is 0; changing the cutoff alters the reminder rule, not the score. Each wrong answer has specific feedback and retry is available.
- **Shared code touched:** None. `LessonFrame` receives explicit Chapter 6 label and `/course/chapter-6` link. Existing shared components are unchanged.

- Used native HTML/CSS diagrams instead of raster images; the arithmetic stays selectable and readable at narrow widths, so no image provider was needed.

- Kept the bias fixed in the weight explorer to focus the interaction on the curriculum's weight outcome; the lesson separately demonstrates bias numerically.
