- **Interaction:** `ExamplesLab` — a scripted bakery staff-board simulation where the learner switches between 5 prompt presets (`0 examples`, `1 example`, `3 varied examples`, `Messy examples`, `New chat (no examples)`) while the task instruction and target staff note stay identical. The learner observes the prompt context update, the illustrative reply style shift (or blur with messy examples, or reset in a new chat), a `What shifted` explanation, a polite live-region announcement, and a persistent `Model weights: unchanged` badge, plus a `Reset` button.
- **Knowledge check:** Shared `Check` component testing why a brand-new chat without examples returns to a plain two-sentence style even after 3 examples worked in an earlier chat. Correct option at index `2` (3rd of 4). Wrong-option feedback:
  - Option 0 (forgot training after 10 minutes): explains time passing did not erase training because earlier examples never changed model weights.
  - Option 1 (examples stop working after one message even in the same chat): explains many chat apps re-send earlier turns inside the same conversation's context window, whereas the scenario opened a brand-new chat.
  - Option 3 (three examples are too few): notes the scenario stated the three examples worked in the first chat; they stopped applying because they were no longer in the prompt.
- **Shared code touched:** none. Existing lessons render unchanged.

## 5. Decisions and deviations

- **Shared instruction held constant across presets:** Rather than giving zero-shot a vague request, all five presets use the exact same instruction so the learner isolates what examples contribute.
- **Responsive 3-card grid in `#shot-counts`:** Replaced an initial 3-column HTML table after 390px screenshot inspection showed the third column clipping inside horizontal scroll; a 3-card grid (stacking to 1 column under 700px) keeps every label and description readable with zero horizontal scroll.
- **Image provider fallback:** `agy-gemini` (`gemini-3.1-flash-image`) returned `429 RESOURCE_EXHAUSTED` (quota reset ~5h); followed `references/tooling.yaml` fallback order and generated both images via `codex exec --sandbox workspace-write`, visually inspected both PNGs for exact spelling and forward-only arrows, and converted both to 1200x800 WebP.
