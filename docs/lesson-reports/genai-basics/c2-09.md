## 5. Decisions and deviations

- The factual prompt uses an invented model that is wrong, so the lab can show low temperature making a wrong answer more certain. The real-world capital is stated only as the "(correct)" label.
- Playwright's port 3100 was held by another worktree's dev server (c2-10), so the full suite was run with a temporary config on another port. The committed config is unchanged.

- Independent Codex review, run until approval: a standard pass (clean), then adversarial passes. Findings fixed: the redraw was not announced to screen readers, copy claimed raising temperature always helps the right answer (the lab shows it peaks near 1), small probabilities rounded to 0% and looked trimmed, and the disclosure ranked the wrong answer second. The last pass approved.
- Review notes handled: the correct quiz option no longer stands out by length, and the sentence about compounding now says the lab does not show it.

- Hydration warning found by the user in the dev server: the probability bar width was an unrounded float (for example 2.199007193577985%), which the server and browser formatted differently. The width is now rounded to 0.1%, the same as the printed percentage. Reproduced in dev with the old code (1 console error) and confirmed fixed (0 errors). The Playwright suite runs against the production build and did not catch this with the old code, so the new console-error assertion is a general safeguard, not a regression test for this exact bug.
