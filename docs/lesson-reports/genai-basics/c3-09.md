## 5. Decisions and deviations

- **Four invented model profiles instead of real commercial models:** Real model names, prices, and leaderboard positions change frequently and go stale. Four clearly disclosed invented profiles (`Quick-Lite`, `Deep-Think`, `Long-Read`, `Local-Safe`) teach the durable five-factor comparison and guarantee unique, unambiguous matcher answers.
- **Image provider fallback:** Per `tooling.yaml`, `agy-gemini` was tried first for all three illustrations. `img2` (`tradeoff-balance.webp`) succeeded on `agy-gemini`, while `img1` returned `429 QUOTA_EXHAUSTED` on `gemini-3.1-flash-image` (reset >4h away). Following `tooling.yaml`, `img1` (`leaderboard-vs-fit.webp`) and `img3` (`hard-limits-filter.webp`) were generated with the fallback provider `codex` using the exact same filled prompts, visually inspected, and converted to 1200px WebP.
- **Radio inputs inside `<fieldset>` for Scenario Matcher:** Using native `<input type="radio">` inside `<fieldset>` + `<legend>` gives built-in Arrow-key navigation, clean focus rings, and avoids conflicts with global `app/studio.css` button hover rules.
