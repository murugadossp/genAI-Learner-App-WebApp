- **Interaction:** `VerifyLab` walks the learner step by step through Maya’s flawed AI draft for the invented Riverbend Community Pool:
  - Step 1 (Fact check): learner opens the Official 2026 Notice and compares the AI’s age cutoff (“under 10”) against the primary record (“ages 5 and under”).
  - Step 2 (Source check): learner can try “Ask AI: ‘Are you sure?’” (shows scripted smooth false reassurance repeating Section 4) and open the Official 2026 Notice (shows a single-page notice with no Section 4 and weekend-only booking).
  - Step 3 (Optional code check): learner runs preset whole-year test cases (`Age 30 (normal)`, `Age 5 (boundary)`, `Age 65 (boundary)`, `Age 3 (under 5)`) against an illustrative `if` / `else if` / `else` pseudocode rule to see how normal cases pass while boundary cases catch `< 5` and `> 65` overcharging.
  - Progress counts a check as verified only after the learner both performs the independent check (opens the notice in Steps 1–2, or runs Age 5 / Age 65 in Step 3) and selects the right verdict; Reset clears all state.
- **Knowledge check:** City parking rule with a formatted citation (“Municipal Code Section 12.4 — Free after 6 PM”). Correct option at index `1` (“Open the official city parking code yourself to check Section 12.4 and the 6 PM rule.”). Wrong options:
  - `0`: trusting a numbered code section as proof of lookup -> explains models can invent section numbers or pair a real section with the wrong rule.
  - `2`: asking the same chat to quote Section 12.4 -> explains asking the same chat is not an independent check and can produce a matching fabricated quote.
  - `3`: keeping 6 PM while deleting the section number -> explains removing the citation hides the source without checking whether the 6 PM rule is accurate.
- **Shared code touched:** none. Existing lessons render unchanged.
