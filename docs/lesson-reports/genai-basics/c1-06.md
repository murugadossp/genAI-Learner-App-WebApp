## 3. What was built

- **Files added:** `src/lessons/genai-basics/c1-06/` (`meta.json`, `Lesson.tsx`, `tasks.ts`, `Grid.tsx`, `RateLab.tsx`, `lesson.module.css`), `tests/web/c1-06.spec.ts`, this report.
- **Interaction:** the learner rates six invented tasks of "Sam" on two questions (stakes low/high; checkability easy/hard). Each choice gets axis-specific feedback; a correct pair reveals the check level. Score and Reset. A small code-drawn grid (stakes down, checkability across) is reused in three sections.
- **Knowledge check:** a scenario about an exact date for a small local fair with a non-refundable trip. Correct option is position 3 of 4 (index 2). Wrong options: (1) fluent and exact is not support; (2) event size is no reason to trust; (4) asking the same assistant again is not an independent check.
- **Shared code touched:** none. `LessonFrame` gets its own `chapter` prop (AI foundations, `/course/chapter-1`). Existing lessons unchanged.
