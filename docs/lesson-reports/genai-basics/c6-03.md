## 2. Curriculum alignment

- **Misconception addressed:** Learning is instant.
- **Prerequisites and adjacent lessons:** prerequisite c6-01; adjacent c6-02, c6-04 and c6-05.

## 3. What was built

- **Files added or changed:** `src/lessons/genai-basics/c6-03/meta.json`, `Lesson.tsx`, `GradientLab.tsx`, `gradient.ts`, `lesson.module.css`; `tests/web/c6-03.spec.ts`; this report.
- **Content added after user feedback (if any):** None.
- **Interaction:** Learners adjust the learning rate, step a marker down a one-parameter loss bowl, run eight more steps or reset. The prediction and loss readouts update together to show that small rates move gradually and an overly large rate can overshoot and raise loss. The marker is a discrete visual for calculated updates; it has no simulated momentum.
- **Knowledge check:** Given the stated toy model and learning rate 0.25, learners calculate the setting after one update. The correct answer is option 3 of 4 (`w = 1`). The other options explain that the step does not jump to the target, a negative slope moves right under the subtraction rule, and this toy update does not wait for a whole dataset.
- **Shared code touched:** None. `LessonFrame` receives explicit Chapter 6 context (`Neural Networks and Deep Learning`, `/course/chapter-6`) as required; shared components and existing lessons are unchanged.
