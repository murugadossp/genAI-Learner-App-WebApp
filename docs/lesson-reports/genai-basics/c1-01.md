## 2. Curriculum alignment

- **Learner outcome:** Explain the four nested rings; AI also includes rule-based approaches, so rules and learning are both AI. Include concrete task examples (predict, classify, recommend, generate).
- **Misconception addressed:** Only systems that learn count as AI.
- **Prerequisites and adjacent lessons:** none (1.1 is first). Next is 1.2 (c1-02, everyday products), which goes deeper on task types.
- **Out of scope:** how learning works (features, labels: c1-03), model versus app (c1-04), training versus inference (c1-05), how any real product is built.

## 5. Decisions and deviations

- Ring labels use nested rounded rectangles, not circles, so labels stay readable at 390px.
- The ring diagram is `aria-hidden`; an always-visible Inside/Outside list carries the same information as text.
- Live region announces only on a choice change and reset, one short sentence.
- Added `/course/chapter-1` rather than overloading `/course`, because `Course.tsx` was fixed to chapter 2 and the lesson's back link must not point to the wrong chapter. The gating test now also expects it to 404 in production.
- No expanded workspace, so no focus or Escape handling applies.
- The takeaway has no "next lesson" link because c1-02 does not exist on web yet.
