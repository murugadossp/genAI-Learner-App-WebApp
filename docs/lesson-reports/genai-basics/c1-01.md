## 2. Curriculum alignment

- **Learner outcome:** Explain the four nested rings; AI also includes rule-based approaches, so rules and learning are both AI. Include concrete task examples (predict, classify, recommend, generate).
- **Misconception addressed:** Only systems that learn count as AI.
- **Prerequisites and adjacent lessons:** none (1.1 is first). Next is 1.2 (c1-02, everyday products), which goes deeper on task types.

## 3. What was built

- **Files added:** `src/lessons/genai-basics/c1-01/{meta.json,Lesson.tsx,RingDiagram.tsx,Sorter.tsx,lesson.module.css}`, four illustrations in `public/lessons/c1-01/*.jpg`, `tests/web/c1-01.spec.ts`, `src/studio/ChapterCourse.tsx`, `src/studio/CourseChapter1.tsx`, this report.

- **Structure:** one short section per ring (AI, machine learning, deep learning, generative AI), each with an illustration, a plain definition, an "In Postbox" example and the same nested-rings diagram with that ring highlighted, so each concept can be placed against the others. Single-column and readable at 390px.
- **Interaction:** a sorter of six parts of the invented mail app "Postbox". For each, the learner picks the innermost ring it belongs to. Feedback is specific: correct explains why; too far out says it belongs to a more specific ring; too far in says it goes less far. Answers can be changed; a score and Reset are provided.
- **Knowledge check:** a chess program with hand-written search and scoring and no training. Correct option is position 3 of 4 (index 2). Wrong 1: playing well does not mean learning. Wrong 2: AI is defined by the task, hand-built rules and search are classic AI. Wrong 4: generative means trained to produce new content, which this is not.
- **Shared code touched:** `LessonFrame` gets an optional `chapter` prop (label, href) defaulting to the previous "How GenAI works" and `/course`, so chapter 2 lessons render unchanged. `Course.tsx` body moved to `ChapterCourse.tsx` taking per-chapter copy; `Course.tsx` passes the original chapter 2 copy. New generated route `/course/chapter-1` (gitignored, 404 in production like `/course`). Existing specs pass unchanged.

## 5. Decisions and deviations

- Replaced the first version, a 4x4 "job by build" explorer, after review feedback that it was confusing and hard to correlate. Concepts are now explained separately, each tied to the same ring diagram, followed by a simpler sorter.
- Ring labels use nested rounded rectangles, not circles, so labels stay readable at 390px. Each diagram has an `aria-label` and a text line; the visual copy is `aria-hidden`.
- Illustrations were made with Codex, converted to JPEG (about 100 KB each) and shown with descriptive alt text. They have a light background and sit in a bordered frame, so they read in both themes.
- Live region announces one short sentence per sorter choice and on reset.
- No expanded workspace, so no focus or Escape handling applies.
- The takeaway has no "next lesson" link because c1-02 does not exist on web yet.
