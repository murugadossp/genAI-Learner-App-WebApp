## 2. Curriculum alignment

- **Learner outcome:** Compare subgroup results, not just averages.
- **Misconception addressed:** Average accuracy shows fairness.
- **Prerequisites and adjacent lessons:** c5-08 (accuracy, precision and recall); c5-09 precedes this lesson.
- **Out of scope:** Diagnosing why a disparity exists, changing a model to address it, and choosing a universal fairness definition.

## 3. What was built

- **Files added:** `Lesson.tsx`, `SubgroupLab.tsx`, `lesson.module.css`, `meta.json`, three WebP illustrations, `tests/web/c5-10.spec.ts`, and this report.
- **Interaction:** Learners regroup the same 200 invented CityBus calls by accent, line quality, or both, then compare accuracy, missed urgent rate, and false alarm rate. Reset returns to the combined accuracy view. Values are labeled illustrative.
- **Knowledge check:** A fictional clinic has 91% overall accuracy across 850 younger and 150 older adults. The correct answer is option 3: compare accuracy and important error rates by age, then inspect relevant combinations when sample sizes allow. Wrong-option feedback explains how group size can mask a result, why removing age does not establish equal performance, and how matching accuracy can hide different error types. Retry is available.
- **Shared code touched:** None. The existing shared lesson frame and quiz are reused; existing lessons render unchanged by inspection and the production test suite.
